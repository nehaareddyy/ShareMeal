# 🍱 ShareMeal

### Connecting Surplus Food Donors with Communities in Need

ShareMeal is a Java and MySQL-based food donation management system designed to connect surplus food donors with NGOs and volunteers.

## 🎯 Problem Statement

Large amounts of edible food are wasted at colleges, restaurants, and events, while many people struggle to access food. A lack of coordination between donors and recipient organizations makes timely food redistribution difficult.

## 💡 Proposed Solution

ShareMeal aims to provide a common platform where donors can list surplus food and NGOs or volunteers can find and claim available donations before they expire.

## ✨ Planned Features

- **Donor Portal:** Add food type, quantity, pickup location, and expiry time.
- **NGO & Volunteer Portal:** View available food and claim donations.
- **Food Status Tracking:** Track whether food is available or claimed.
- **Admin Panel:** Manage users, food listings, and pickup records.

## 🛠️ Technology Stack

- Java
- Java Swing
- MySQL
- JDBC (Java Database Connectivity)

## 🏗️ Project Status

🚧 Currently in development. Features will be implemented and tested progressively.

## 🌱 Our Goal

To use technology to reduce avoidable food waste and make surplus food donation coordination easier.
